# Stumble

Rediscover the internet. One click, one random website from the indie web.

A Chrome extension that brings back the magic of StumbleUpon by pulling from multiple curated feed sources across the indie/small web.

## Development

1. Open `chrome://extensions` in Chrome
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select this folder
5. Click the Stumble icon in your toolbar and hit the button!

## Current Feeds

- **Wiby.me** — Retro & personal websites from the old web
